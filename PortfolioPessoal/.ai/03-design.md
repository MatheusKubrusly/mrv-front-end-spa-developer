# 🎨 Design System e UI/UX

## Identidade Visual
* **Paleta de Cores:**
  * Fundo Secundário/Cards: [Ex: #1E293B]
  * Texto Principal: [Ex: #F8FAFC]
  * Cor de Destaque (Accent): [Ex: #38BDF8]
* **Tipografia:** [Ex: 'Inter' para textos longos, 'CalSans' ou 'Poppins' para títulos].

## Layout: Estética Bento Box
* Utilize o conceito de **Bento Grid** para a seção de Habilidades, Links Sociais e Prova Social (feedbacks curtos).
* **Regras do Bento:** Bordas arredondadas consistentes, sombras sutis (ou glow effect), espaçamento (gap) uniforme e formato assimétrico elegante.
* Fundo com leve transparência (Glassmorphism) é encorajado para os cards.

## Interações e Animações
* **Filtros Dinâmicos:** Transições suaves ao filtrar a visualização de projetos por categoria (ex: Front-end, Back-end).
* **Micro-interações:** Hover states interativos e bem definidos em absolutamente todos os elementos clicáveis (botões, links, cards).
* **Scroll:** Animações de entrada sutis (fade-up ou reveal) ao rolar a página para novas seções.

## Responsividade
* **Mobile-First Rigoroso:** O design deve ser pensado primeiramente para celulares.
* O Bento Grid deve colapsar perfeitamente para uma coluna única em telas menores.
